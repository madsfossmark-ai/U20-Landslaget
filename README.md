# Norge U20 kvinner – statistikk

Åpen kampstatistikk for Norges U20-landslag (kvinner) i NEVZA 2026, Rovaniemi 23.–25. oktober (1. runde i kvalifiseringen til U20-EM 2027).

**Se siden:** https://madsfossmark-ai.github.io/U20-Landslaget/

Siden viser Norges kamper, de andre lagenes kamper, tabell og sluttspill. Statistikken føres fra benken i appen og publiseres hit etter kampene. Andre lags resultater føres manuelt.
